# Sophon 1.1.0

This update expands app interaction and improves how Sophon checks the results of
desktop actions, coding tasks, and learned procedures.

## New and improved

- **Browser interaction:** Sophon can open a dedicated Edge or Chrome session,
  inspect page controls, and interact with them through the page DOM. Sign in
  within that browser session; it keeps its own profile.
- **App routing:** Sophon can discover matching connected MCP tools and choose
  between connected tools, browser controls, Windows accessibility, and screenshots
  according to the task and granted permissions.
- **Windows accessibility:** Faster property discovery, focused searches, paged
  results, and optional post-action inspection help with complex app interfaces.
- **Screenshot interaction:** Bounded captures, detailed crops, optional unchanged
  image suppression, and post-click captures reduce repeated visual work.

## Reliability fixes

- Track action evidence across tool routes and require verification before
  reporting a task as completed. Accepted input alone does not prove success.
- Bind coding checks to the changes they verified, including workspace mutations,
  failed checks, interrupted work, and uncertain command outcomes.
- Save procedure content and lifecycle state together, and aggregate outcomes by
  run and version. Generated guidance is no longer promoted just because tool
  executions succeeded.
- Clarify memory privacy, permission behavior, and app interaction setup in the
  documentation.

## Updating and setup

- **Installer:** `Sophon-1.1.0-setup.exe` (Windows).
- This release is unsigned, as was 1.0.0. Windows may display a SmartScreen warning.
- New browser tools remain blocked in existing profiles until enabled in
  **Settings > Permissions > Browser interaction**. Edge or Chrome must already
  be installed. Connected app tools require configuration in **Settings > Plugins**.
- The dedicated browser session does not import accounts or cookies from your
  normal browser profile.

Sophon remains a work in progress. Keyboard input can still be incomplete in some
desktop apps. Browser and accessibility fixture checks do not establish support
for every app, and live Discord interaction has not been verified. End-to-end
updating from 1.0.0 must be tested; if the updater rejects an unsigned installer,
download and run the installer manually from this release.
